The problem

The paperwork
is only one story.

Why compare factory declarations with evidence from outside the paperwork?

The project’s problem statement

A GST officer can’t tell which factories are hiding production or inflating tax credits, because every document she checks is declared by the factory itself, while the independent evidence (power use, goods movement, supplier records, bank flows) sits in separate places and is never compared. If this worked, she would start each week with a short list of units whose paperwork contradicts physical reality, each contradiction spelled out, and honest-but-unusual factories cleared.

Different records.
Different questions.

What was declared?

GSTR-1 records outward supplies. Supplier filings also feed the information used for input tax credit (ITC). GST Portal guidance ↗

What moved?

An e-way bill is an electronic record associated with goods movement. It gives this prototype another record to compare with invoices. GSTN explanation ↗

What supports the credit?

GSTR-2B helps taxpayers review input tax credit information. This prototype models supplier-return reconciliation; it does not connect to the GST portal. GST Portal guidance ↗

Designed for
the GST officer.

The workflow we target is reviewing declarations when supporting records arrive separately. This is a prototype problem framing, not a claim that every existing tax system ignores these records.

We test whether cross-source contradictions can make that review more focused, while keeping honest exceptions and missed cheats visible.
