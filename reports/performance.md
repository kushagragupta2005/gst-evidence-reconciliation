# Historical workload report — DEV

This file records a local synthetic workload generated before the current detector changes. It is **DEV** evidence only and must not be used as a current-detector benchmark or an engine-superiority claim.

The raw machine-readable observations remain in `benchmark_small.json`, `benchmark_full.json`, `profile_small.json`, `profile_full.json`, and the dataframe comparison fields of those files. Any future benchmark must use the current detector, declare hardware and database allocation, repeat the same workload across engines, and retain every run.
